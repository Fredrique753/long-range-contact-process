# Long-Range Contact Process Boundary Prediction

This project studies the spatial growth geometry of a long-range
Contact Process and uses a neural-network surrogate model to predict
the boundary coordinate y from the infection parameter lambda,
the long-range exponent alpha, and the horizontal coordinate x.

## Methods

- Long-range Contact Process simulation
- Monte Carlo replication
- Boundary extraction from the cumulative occupied region
- Neural-network regression
- Model comparison with linear regression, random forest and
  support vector regression
